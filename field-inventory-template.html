F2 · Task and Data Plan

Task: Plant swap registration. Every value below is needed to plan tables and confirm a spot. No last name, phone, address, or age is collected.

Visible label / question Why necessary now? Required? Native control/type Submitted name/value Autocomplete/inputmode Constraint/instruction Sensitivity and minimization decision
First name or nickname Organizers use it to greet you and make your name tag. Yes input type="text" name="nickname" autocomplete="given-name" Up to 40 characters (maxlength="40"). Low. Only a first name or nickname is asked for; no last name.
Email address Needed to send the registration confirmation and swap details. Yes input type="email" name="email" autocomplete="email" Must be a full address. Example shown: name@example.com. Medium (contact info). Used only for this event. No phone number is collected.
Send me a reminder the day before Lets people choose whether they want one extra email. No input type="checkbox" name="reminder" value="yes" N/A None. Unchecked by default (opt-in). Low. Optional, and off unless the user turns it on.
Which session? Organizers need to know how many people come to each session. Yes select name="session" values: sat-am, sat-pm, sun-am N/A Choose one. First option "Select a session" has an empty value so required works. None. Not personal information.
How many plants are you bringing? Used to plan table space for the swap. Yes input type="number" name="plant_count" inputmode="numeric" Whole number from 1 to 5 (min="1" max="5"). None. Not personal information.
What kinds of plants? Helps organizers group similar plants on the same tables. No input type="checkbox" group (fieldset + legend) name="plant_types" values: succulents, houseplants, herbs, cuttings N/A Choose any that apply. None. Not personal information.
Care level of your plants Lets tables be labeled so swappers find plants that match their experience. Yes input type="radio" group (fieldset + legend) name="care_level" values: easy, medium, expert N/A Choose one. None. Not personal information.
Plants you're hoping to find Helps organizers suggest good trades. No textarea name="wishlist" N/A Up to 300 characters (maxlength="300"). Low. Help text asks users not to include personal details.
I confirm my plants are free of pests Protects other swappers' plants from bugs and disease. Yes input type="checkbox" name="pest_free" value="confirmed" N/A Must be checked to submit. None. Not personal information.
